# Clash Royale API validation

Дата проверки: 20 августа 2026 года. Токен и заголовки авторизации в отчёт не
записывались.

## Leaderboards

- `GET /v1/locations?limit=1000`: 262 локации, из них 254 страны.
- Глобальный `pathoflegend` с лимитом 1000 вернул ровно 1000 игроков.
- Пагинация с лимитом 50 вернула последовательные диапазоны рангов без
  пересечений.
- Полный последовательный обход 254 стран: 254 успешных ответа, 34 370
  уникальных игроков, 3 мин 48 с.
- Тот же обход с четырьмя рабочими потоками: 254 успешных ответа, 34 376
  уникальных игроков, 39,4 с, ни одного ответа HTTP 429.
- В повторном полном цикле синхронизации и атомарной публикации SQLite было
  записано 34 410 активных игроков за 16,0 с.
- Заголовок API содержал `Cache-Control: max-age=58`; явных заголовков лимита
  запросов не было. Приложение использует четыре рабочих потока и бережный
  пятиминутный цикл обновления.

## Поиск

На опубликованном снимке выполнено 1000 запросов только по рейтингу:

- медиана: 1,313 мс;
- p95: 16,6 мс;
- среднее число кандидатов в диапазоне ±48: 1425.

Уникальным ключом служит тег игрока. Новый снимок заменяет активную таблицу
только после успешной загрузки всех стран.

## Battle log и карты

- Battle log тестового игрока вернул 30 записей `pathOfLegend`.
- В каждой проверенной команде было восемь карт.
- Время боя соответствует формату `20060102T150405.000Z`.
- Каталог карт вернул 122 карты: у всех было обычное изображение, у 41 — также
  изображение эволюции.
- Финальный живой smoke-тест приложения: 254 кандидата для запроса `2500`, три последние
  Ranked-колоды, 24 корректных локальных data-image.
- Дополнительная проверка форм показала: `evolutionLevel=1` обозначает выбранную
  эволюцию, `evolutionLevel=2` — выбранную геройскую форму. Наличие формы в
  каталоге само по себе не означает, что она использована в конкретной колоде.
- Каталог уже отдаёт `heroMedium` для героев. Для новой эволюции Elite
  Barbarians battle log передаёт выбранную форму, но официальный каталог пока
  не передаёт отдельный URL изображения; приложение использует точечный
  актуальный резервный арт до обновления официального метода.

## Сезоны

Метод сезонов на момент проверки возвращал завершённые сезоны; максимальный
маркер был `2026-07`. В старых данных обнаружен повтор `2016-02`, поэтому маркер
выбирается как максимальный идентификатор, а не как первый элемент ответа.
