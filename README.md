# Royale Scout

**Royale Scout** — локальное Windows-приложение для ручного поиска соперника Clash Royale по Ranked-медалям и части ника. Оно показывает до трёх последних Ranked-колод и отдельно выделяет настоящие заклинания.

## Главное

- без регистрации, аккаунтов Royale Scout и собственного сервера;
- без OCR, захвата экрана, управления игрой и вмешательства в клиент Clash Royale;
- без аналитики и истории поисков;
- личный API-токен шифруется Windows DPAPI и остаётся на компьютере пользователя;
- сетевые запросы разрешены только к `api.clashroyale.com` и `api-assets.clashroyale.com`;
- интерфейс на русском и английском языках.

## Установка

1. Откройте раздел **Releases** на странице репозитория.
2. Скачайте ZIP для Windows x64 и файл `SHA256SUMS.txt` из одного релиза.
3. При желании проверьте контрольную сумму:

   ```powershell
   Get-FileHash .\RoyaleScout-v0.2.0-windows-x64.zip -Algorithm SHA256
   ```

4. Распакуйте ZIP в обычную папку и запустите `RoyaleScout.exe`.

Приложение пока не подписано платным сертификатом, поэтому Microsoft Defender SmartScreen может показать предупреждение «Windows защитила ваш компьютер». Скачивайте приложение только из Releases этого репозитория, сверяйте SHA-256 и не запускайте копии из случайных источников.

Для дополнительной проверки установите [GitHub CLI](https://cli.github.com/) и подтвердите, что ZIP действительно создан GitHub Actions из этого репозитория:

```powershell
gh attestation verify .\RoyaleScout-v0.2.0-windows-x64.zip --repo untill265/royale-scout
```

В каждом релизе также публикуется файл `sbom.spdx.json` — машиночитаемый список компонентов и зависимостей сборки.

## Первый запуск и API-токен

Для работы нужен бесплатный личный ключ официального Clash Royale API. Игровой логин, пароль и тег игрока приложению не нужны.

1. Откройте [Clash Royale Developer Portal](https://developer.clashroyale.com/).
2. Войдите или создайте учётную запись.
3. В **My Account** выберите **Create New Key**.
4. Укажите свой текущий публичный IPv4 в разрешённых адресах и создайте ключ.
5. Скопируйте токен целиком, вставьте его в Royale Scout и нажмите **Проверить и сохранить**.

Приложение проверяет ключ прямым запросом к официальному API и сохраняет его в зашифрованном виде для текущей учётной записи Windows. Сохранённый токен нельзя посмотреть в интерфейсе — только заменить новым через **Настройки**.

Если провайдер сменит публичный IP, обновите адрес ключа на портале или создайте новый ключ, затем выберите **Настройки → Заменить токен**.

## Как искать

Введите число Ranked-медалей и, желательно, часть ника: `2910 су`. Поиск охватывает диапазон ±48 медалей. Если совпадение одно, колоды откроются сразу; если их несколько, приложение покажет список кандидатов.

Флажок **Есть иероглифы** оставляет только ники с китайским, японским, корейским или арабским письмом. Без флажка проверяются все ники, включая такие. Эмоции не считаются.

## Приватность и локальные данные

Подробная модель данных описана в [PRIVACY.md](PRIVACY.md). Коротко:

- введённые ники и медали не сохраняются;
- локальная база рейтинга, кэш карт и зашифрованный токен находятся в `%LOCALAPPDATA%\RoyaleScout`;
- ник и медали сопоставляются с локальной базой; в официальный API отправляется тег выбранного игрока для загрузки battle log;
- удалить всё можно внутри приложения: **Настройки → Удалить все локальные данные**.

## Безопасность

Каждый новый релиз публикуется только после успешных тестов, `npm audit`, `govulncheck` и сканирования готового архива ClamAV. Изменения исходного кода дополнительно анализируются CodeQL. GitHub подписывает аттестацию происхождения ZIP, а SHA-256 и SBOM публикуются рядом с ним. Результаты всех этапов открыты во вкладке **Actions**.

Эти проверки существенно повышают прозрачность, но не являются абсолютной гарантией безопасности. Архитектура защиты и порядок сообщения об уязвимостях описаны в [SECURITY.md](SECURITY.md). Никогда не публикуйте свой API-токен в issue, скриншоте или логе.

## Сборка из исходников

Требуются Windows 10/11 x64, Go 1.25+, Node.js 24+, npm и Wails CLI 2.15.0.

```powershell
npm ci --prefix frontend
npm run build --prefix frontend
go test ./...
go vet ./...
wails build -clean -trimpath -platform windows/amd64 -o RoyaleScout.exe
```

Для локальной разработки:

```powershell
wails dev
```

Сборка релизного ZIP:

```powershell
.\scripts\package-release.ps1 -Version 0.2.0
```

CI проверяет проект на Windows, а workflow релиза собирает, инвентаризирует, сканирует и аттестует ZIP при публикации тега вида `v0.2.0`.
